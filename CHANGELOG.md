# Changelog

## 0.3.0 — Provider-independent technology baseline
- Selected an online-first, provider-independent inference architecture.
- Separated Senorita's local control plane and agent runtime from model inference.
- Added the internal Model Gateway, provider adapter, capability-aware routing, privacy, budget, fallback and usage-audit requirements.
- Defined FreeLLMAPI and OmniRoute as candidates requiring technical verification before integration.
- Kept Ollama/local models optional rather than a hardware prerequisite.
- Updated architecture decisions, requirements, roadmap and implementation backlog.

Documentation and architecture only; no runtime capabilities are implemented yet.

## 0.2.0 — Initial SPS foundation
- Reframed Senorita as Self-Programming Software.
- Added trusted-foundation and evolutionary-system architecture.
- Defined continuous autonomous evolution lifecycle.
- Added source, component and knowledge absorption model.
- Defined bounded autonomy, provenance, verification and recovery.
- Added requirements, roadmap and initial implementation backlog.

Documentation and architecture only; no runtime capabilities are implemented yet.
